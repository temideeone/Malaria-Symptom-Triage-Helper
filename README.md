# Malaria Symptom Triage Helper

## Overview

This project develops a machine learning-based malaria symptom triage helper that analyzes patient-reported symptoms and predicts malaria risk. The system is intended as a decision-support tool to encourage timely medical evaluation and does not replace professional diagnosis.

## Objectives

* Collect and analyze malaria symptom data.
* Perform exploratory data analysis (EDA).
* Train and compare multiple machine learning models.
* Select the best-performing model.
* Deploy the solution as a Streamlit web application.
* Produce a comprehensive academic report.

## Models to Compare

* Logistic Regression
* Decision Tree
* Random Forest
* Support Vector Machine (SVM)
* K-Nearest Neighbors (KNN)
* XGBoost
* LightGBM
